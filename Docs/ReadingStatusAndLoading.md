# 页码、内容边界与连续加载管理

> 本文为页码与加载阶段记录。文末未实现项已有后续进展，当前能力以 README 和 [纸张曲面与原位替换](PaperAndPageReplacement.md) 为准，阶段测试数保留。

本轮在第一个运行里程碑上继续实现用户提出的当前页码、总页数、末页与最新页，同时接入连续加载任务所有权及交互中延期安装。保持 iOS 15／Swift tools 5.9／UIKit／无第三方依赖，未修改 ParsingBook 宿主源码。

## 页码统计口径

`ReaderPageMetrics` 表示一个统计范围：`current` 从 1 开始，nil 表示未知；`total` 分为 unknown、estimated、exact。确定总数允许零，但零页时不能同时有当前页；当前页不能超过确定总数。估算允许暂时低于当前位置，不据此判断末页。

`ReaderPagination.book` 是全书当前快照的统计，`section` 具有稳定章节 ID 及本章统计。计数单位分别为排版页、源图页、内容块。章节页码、全书页码、已加载窗口长度不能混为一谈；连续滚动不会从 contentSize 或块数量伪造全书页数。

- 小说页数取决于当前字体、版心、尺寸和布局版本，由宿主排版器提供。
- 漫画源页数由宿主目录提供，独立于长图切片等展示单元；双页／切片的完整适配仍未实现。
- 示例小说只按短段落块统计，明确显示“段”；漫画示例显示“源页”。

## 首末边界与最新内容

| 信息 | 何时成立 | 不能推断什么 |
| --- | --- | --- |
| `isFirst` | 当前统计号码为 1 | 未提供全书统计时不能推断全书首页 |
| `isLast` | 当前号码等于确定总数 | 不等于全书完结或用户已读完 |
| `startOfBook` | 宿主确认全书起点 | 与本章首页分别处理 |
| `endOfSection(id)` | 指定章节供给结束 | 后面可能还有章节 |
| `end` | 当前所供窗口没有更多内容 | 不知道全书是否结束 |
| `endOfBook` | 宿主确认完整内容结尾 | 不自动触发宿主“已读完”业务 |
| `latestAvailable` | 当前连载快照最新内容 | 后续可追加，并不等于完结 |
| `unknown/available/loading/failed` | 边界未知、可继续、等待、失败 | 均不能当作末页或最新页 |

`PageAvailability.boundary` 允许分页宿主返回这些明确边界；未提供 pageProvider 时按 waiting 处理。保留旧 `.end` 兼容表达供给边界，不再让它暗指全书结束。

分页的 `PageContent.readingInfo` 随页面事务提交。取消不改变当前页码，成功后更新号码与边界。`updateReadingInfo` 可以补全总数、处理连载更新，但必须携带当前 `metadataToken`；切页、尺寸变化、统计更新都使旧令牌失效。

先交付完整 commit／settle，再发布成功后的阅读状态，状态回调中退出或切换模式不会漏掉翻页终态。等待／失败的邻页恢复可用后，即使随后取消手势，仍保留 available 边界，当前号码不变。

连续模式从顶部可读内容块取当前位置和统计，仅在真实滚动边缘报告末尾／最新。底部到书尾时，顶部可能仍在前一页，SDK 不强行把当前位置改成末页。回弹不会宣布书尾，加载／错误占位不会冒充可读页码。

连续视口尺寸改变会暂时排除旧 layoutPage 计数，新的窗口安装后才恢复；源页／内容块计数不依赖排版尺寸。连续块跨多个排版页时，宿主仍需按语义位置解析当前页，SDK 不按像素距离猜算。

`readingStatus` 支持主动查询，`onReadingStatus` 只在状态变化时回调。它服务页眉页脚／按钮等显示，不替代稳定位置保存；宿主持久化仍应使用稳定语义位置。

## 连续加载所有权

完整流程：

```text
边界需求 → beginLoading 登记唯一任务
         → 宿主读取／排版
         → submit 提交完整窗口
         → 若交互占用则保留结果
         → 空闲时捕获当前锚点并安装
         → completion(.installed(新窗口令牌))
```

- 同方向同窗口版本去重；双方向任务可各自存在。
- 完整窗口采用“最新已就绪结果优先”，新结果覆盖旧准备结果时明确终止旧任务。
- 一个窗口安装后，基于旧令牌的并发另一方向任务以 superseded 结束；宿主重新基于最新窗口合并。
- 拖动、减速或多原因暂停期间不会替换视图；全部恢复后安装时重新捕获锚点，避免拉回提交结果时的位置。
- 显式导航、尺寸变化、直接窗口更新、renderer 失效会终止对应旧任务。
- 每个被接受任务只有一次终态：installed、superseded、cancelled、invalidated 或 rejected。
- 先清除旧所有权，再执行取消和终态回调；清理过程中拒绝新任务、apply／restore，宿主重试或定位安排到下一主队列事务，避免消耗无法登记的边界需求。
- 成功安装不调用取消句柄；其他终态会调用。宿主应使任务取消幂等。
- 窗口通过校验并开始提交时，先冻结安装票据；provider 的 bind／unbind 同步取消不能把已提交安装改成 cancelled。真实视图安装后才回调 installed；中途 renderer 失效则仅回调 invalidated。
- `apply` 保持立即安装语义，交互中拒绝；需要自动延期的异步任务使用 beginLoading／submit。
- SDK 不执行网络或文件读取，也不解释加载错误文案。宿主主动取消用 cancelLoading，报告失败用 rejectLoading。

## 示例与验证

`Examples/ReaderDemo.xcodeproj` 增加完整内容／连载快照切换、首页、末页／最新、模拟更新。模拟更新追加四个内容单元，当前位置保留，统计总数增长，旧最新页变为可继续阅读。

启动参数 `--comic --serial --last` 用于查看分页最新页，追加 `--continuous` 用于连续书尾。模拟器启动截图已实际观察到：全书 16/16 源页、本章 4/4 源页、已到最新，等待更新。

最终在 iOS 18.6 iPhone 16 Pro 模拟器运行 **68 项 XCTest 全部通过**；其中纯逻辑 **34 项**也在 macOS 独立通过。示例 App Debug 模拟器构建、安装和启动成功，复核修复后再次构建成功。测试覆盖未知／估算／精确页数、单页书、本章末页、最新与完结区分、翻页取消、统计令牌、延期锚点、任务覆盖／取消／失效、同步回调结果与短章节连续补屏。

最终会话 scratch 证据：`page-turn-status-final-tests.log`、`page-turn-status-final-tests.xcresult`、`page-turn-status-final-core.log`、`page-turn-status-final-demo.log`；启动截图 `page-turn-latest-page.png` 展示最新页状态。这些证据不作为 SDK 资源分发。测试有两个弱引用变量的编译器提示、未使用 AppIntents 的元数据提示及 Xcode 自身 invalidDigitCount 诊断；无编译错误或失败断言。

本轮一次代码复核后增加 7 项 UIKit 回归：视图回收中取消不改写安装成功、状态回调退出／模式切换不漏终态、终态回调定位明确拒绝、邻页恢复可用后取消、尺寸变化清除旧排版统计、短章节先确认安装再请求下一章、保留安装期间失效只回调一次。

测试与启动截图不代表真机手势手感、iOS 15 运行时、大量章节或大图的压力验收。本轮尚未实现字符级重新排版恢复、自动阅读、平移／仿真／拱页和漫画双页／切片／RTL。下一阶段继续按连续兼容矩阵与真实宿主内容验收。
