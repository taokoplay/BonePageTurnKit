# 拱页二维跟随与固定书脊弧面

`.paged(effect: .arch, axis: ...)` 使用真实按下点和二维位移。书脊处最初装订的同一条纸边始终固定，按住、斜拖、回拉和松手均不允许材料滑过书脊。

## 参考视频与形态约束

本轮按用户提供的 `IMG_6185.MOV` 实拍纸张参考逐帧检查，时长约 16.135 秒：

- 约 2.0–5.5 秒：手指向书脊推送，书脊到指腹之间的纸段形成宽而连续的弓形，印刷横线随纸面弯曲，指腹处局部贴合。
- 约 8.0–10.5 秒：较深推送使弧面进一步升高，随后回拉展开；装订材料边保持原位。
- 约 12.0–14.5 秒：纸张围绕书脊翻向另一侧并落下，固定边没有跟着整页平移。

固定的是材料边，不是让不同材料轮流经过一条固定的屏幕支撑线。验收必须追踪同一组源材料顶点，不能仅检查画面上是否还存在一条支撑线。

## 几何与接触

纸面使用圆柱／圆锥可展曲面。水平推送是圆柱极限，斜推则以装订边延长线上的点为圆锥顶点；有限接触平面允许整体转动，不用材料剪切强行平移到手指。正翻弯曲当前页，回翻展开原书脊上的上一张纸；回翻控制的是上一张纸的自由边，界面输入仍保留真实按下点与二维位移。

设原抓取点为 `(a,c)`，目标为 `(x,c+q)`，书脊为 `(0,v)`、`0<=v<=b`。不可伸长纸张必须满足到每个固定书脊点的空间距离不大于原材料距离，因此 `x²+q²+2q(c-v)<=a²`。最严约束在书脊两端之一，正横移取 `h=c`，负横移取 `h=b-c`；以 `C=a²-x²` 得到 `|q|<=C/(sqrt(h²+C)+h)`。超界触点连续限位，不能靠拉伸纸面满足不可达的手势。

斜推圆锥顶点为 `A=c+(x²+q²-a²)/(2q)`。在上述约束下，顶点位于装订线的纸页范围之外。材料极坐标中的曲面写作 `P(r,θ)=A+r*d(θ)`，其中 `|d|=1`、`|d'|=1`、`d·d'=0`；其度量为 `dr²+r²dθ²`，与原纸相同，因而保持材料长度与夹角。相邻球面节点用大圆插值，实际渲染三角形沿相同材料射线裁剪，使每个条带保持刚性。

截面按原材料弧长求解隆起幅度，在端点切线平顺的有限曲线族内，以相邻法线转角的弯曲能近似选择更圆滑的形态。该实现是可展运动学与有限族弯曲能近似，未标定纸厚、弹性模量或完整接触动力学。不能把真实三维转向产生的屏幕投影缩短误判为材料伸缩，也不能用缩放纹理模拟转向。

`worldPoint` 与 `height` 保存投影前的纸面；`point` 使用保留的低角斜投影交给绘制器。验收计算实际三角形完整二维雅可比的两个奇异值及材料直角，并检查源面积覆盖；只检查直母线或横向整条长度会漏掉二维剪切。网格显式包含原书脊、抓取点、有限指腹平面与剖面节点；弧面投影和纸边柔影共用 32,768 顶点预算。

松手从最后已提交姿态开始。正翻将受压纸段的展开量与绕原装订线的倾倒角度耦合：正常深推姿态先保留弯曲向翻页侧倾倒，接触边的主轴投影不先向原页回开，再逐渐展平。曲面节点的最大极角限制整体旋转，保持纸面位于底页之上。回翻则让上一张纸从原书脊外展开到本页，取消时沿同一书脊收回。顶点坐标不在两个曲面间线性混合。Metal 与软件绘制同步选择运动纸张、底页和双页材料半页；arch 保留自己的方向与释放起点，原生 follower 重建中间帧时继承回翻限位。

## 宿主接入与保持项

```swift
try reader.beginInteractiveTurn(.next, at: startPoint)
reader.updateInteractiveTurn(to: currentPoint)
reader.endInteractiveTurn(velocity: directionalVelocity)
```

坐标位于 `reader.view.bounds`，包含原点；结束速度沿本次逻辑方向为正。起点必须位于可翻动纸面内，书脊零距离处和双页另一半会在请求邻页或挂载资源前返回 `invalidInteractionPoint`。

按住时的可达范围受整条固定书脊约束，使用上面的双端点距离不等式。极端斜拖仍保留最多 2pt／1% 材料长度的弯曲余量，余量在起止点连续归零。arch 保留完整视口主轴位移 17% 或正向 500 point/s 的完成规则，快速反向和非有限速度取消。

沿用 180ms 可重定向跟手、约 288–360ms 整页播放、收尾倍率 1.2、原生有序渲染时钟、首末帧提交门控、纹理复用、快照预算、连续翻页队列及 Reduce Motion／生命周期策略。curl 的方向、翻卷几何、材质及过半完成规则保持原实现；旧标量 arch 接口保留兼容路径。

## 双页按住时从书脊上方整页翻覆

上一节的分段释放只修正了松手回开，按住时仍沿底页压缩成书脊附近的窄卷，不能满足整页从上方翻过的交互。当前双页正翻统一使用受压剖面与绕原书脊的刚性转角；删除了上一节的分段内外尾部释放实现。单页、回翻、curl 和 reader 收尾时序保持本轮基线。

设原抓取点到书脊的材料距离为 `a`，屏幕有符号端距为 `D`。令 `w=smooth((0.75a-D)/(0.75a))²`、虚拟平面端距 `E=D+(a-D)w`、转角 `θ=acos(D/E)`。起步继续使用原压力拱面，接近书脊时逐步展开内段并抬起整页；`D≤0` 时内段展开为 `E=a`，同一半页绕原装订边以 90° 至 180° 翻到对页上方。原抓取材料不滑动，横移可达量随 `E` 与整条固定书脊的距离约束共同收窄。

圆柱／圆锥材料映射与三角形裁剪保留，随后对整张纸使用同一个刚性转动和统一仿射相机投影。屏幕横轴投影采用转动前高度，因此抬起的有限指腹仍对齐受约束触点；这不是逐列位移补偿或纹理缩放。指腹由贴地平面改为可抬起、可倾斜的刚性平面，单页和回翻仍检查原零高度要求。

取消沿当前端距回到原页；完成沿当前转角继续到对页。完成前先耦合虚拟端距和转角，避免已提交的材料端点朝原页回开。两条路径均从实际按住姿态开始，不在两个三维曲面之间插值。该模型仍是可展运动学与有限曲线族的显示质量近似，不代表标定弹性或有限厚度碰撞求解。

新增回归直接检查双轴双向持握过脊时的整张材料位置、整条自由边抬升、固定原书脊、二维尺度与夹角、完整来源面积，以及释放首步连续性；另检查开始抬页和越过书脊两处各 0.0001pt 的材料轨迹。GPU 采样扩展到手指到达对页外缘的完整持握终点。当前验证结果将在本节补记，旧版 release-only 结果不作为本次完成依据。

## 双页正翻：宽弧经过中缝

当前实现替代上节的近似平板。右页沿原材料长度分带，外缘先抬起，指腹及其外侧沿弧端的切面延续。设原抓取半径为 `a`，有符号屏幕端距为 `D`，弦长取 `a·(1−0.095·(1−(D/a)²))`：书脊正上方仍保留弦与弧的长度差，只有两端落平时才归零。直拖的剖面由等长等转角线段构成；斜拖在单位球上逐段走大圆并转动切线，仍采用原材料射线裁剪，不逐列缩放文字。该模型是可展运动学近似，不是标定过的纸张动力学。

投影中心在书脊上，透视随页高变化；先反解转角，使材料触点的投影仍落在手指处。跨中线时，先越过的纸背覆盖原左页，右侧露出下一页；靠装订端的纸面稍后跟过。松手完成与取消沿同一族曲面向两端推进。单页和回翻不使用这个剖面或透视。回归分别检查实际三维度量、书脊与触点、宽弧的连续转向、过脊左右两侧的材料覆盖以及最终 GPU 像素。

### 恢复拾页时的受压质感

宽圆弧只负责翻越书脊，不再从起手就替代压力拱。拖动量不超过抓取点到书脊距离的 28% 时，双页直接复用原单页的受压剖面、有限指腹、投影与光照。继续深推时，受压材料段逐渐缩短，其外侧以同一切面接上翻起的宽弧；松手与取消亦由同一材料姿态继续。弯曲只改变纸面在空间中的位置，不缩放纹理。单页、回翻和 curl 的渲染路径未改变。

`testSpreadPickupRetainsSingleLeafPressureAndLighting` 在相同尺寸下对照 8、24、40pt 的单页与双页浅拖姿态，检查拱高、拱顶投影、平面指腹、三角形明暗分布及阴影。另对受压段开始和结束交接的位置检查微小拖动的连续性，并保留过中缝时的真实 GPU 覆盖检查。

### 双页往返使用同一张纸

双页正翻与回翻现在用同一书脊、材料坐标、受压剖面和透视。回翻的抓点在材料上对应按下点关于书脊的镜像，不再用最初几 pt 的拖动把页外自由边接到页内手指。纸的正反面、底页仍采样同一组跨页快照，拖动过程中不交换视图。完成和取消分别收敛到正确的铺平姿态。单页回翻继续使用原有自由边规则。

双页抓点越过中线后，即使累计位移不足整屏的 17%，慢速释放也可完成；快速反甩仍取消。在 240pt 画布上以同一内容和外缘抓点，每隔 8pt 比较正反向 GPU 输出：修正前仿真 31 个停点全部匹配，拱页有 29 个停点不匹配；修正后两种效果各自在 31 个停点的解码 RGBA 均逐像素相同。这是来回路径与图层一致性的检查，不是硬件帧率测量。[往返对照视频](SpreadTurnComparison.mp4) 展示同一批等位移采样。
